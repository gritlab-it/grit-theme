# GRIT Theme Guide

This manual covers the fields, classes, and behavior of the starter's components. For installation and initial setup, see [README.md](README.md). [Italian guide](GUIDE_IT.md) · [Italian README](README_IT.md)

Enter classes as space-separated tokens in the indicated fields. Adapt media IDs, slugs, post types, and agency names to your project. Each library needs compatible component markup and configuration.

## Common customizations

Paths refer to the parent theme unless marked **child**.

| Change | Where to start |
| --- | --- |
| Colors | Edit `$accent`, `$primary`, `$secondary`, `$light`, and `$dark` in `assets/css/_variables.scss`. Use `bg-*` and `color-*` in ACF to apply the palette. [Colors and SCSS](#colors-scss-and-customization) |
| Fonts | Set font loading, `$font-primary`, `$font-secondary`, and `$font-base` in `_variables.scss`. Typography rules live in `_typography.scss`. The Customizer's Google Fonts field loads the font. Assign its family in the styles. |
| Buttons | Use the ACF label, link, and class fields. Adjust sizes and corners through `$button-*` in `_variables.scss`, colors through `.btn-*` rules in `_typography.scss`, and markup through `templates/partials/buttons.twig`. [Shared buttons](#shared-buttons) |
| Spacing | Start with `py-5`, `mb-4`, and supported `gap-*` utilities. `$extra-spacing-values` in `_variables.scss` supplies the additional utilities generated by `_content.scss`. |
| Header and footer | Select a variant in the Customizer and assign menus under **Appearance → Menus**. Edit `templates/headers/`, `templates/footers/`, `_header.scss`, or `_footer.scss`. [Headers and footers](#headers-footers-menus-and-forms) |
| Section | Edit content, columns, and classes in ACF first. For markup use `templates/sections/section_NAME.twig` and its partials. Styles live in `_sections.scss`. Changes to the shared `templates/sections/section.twig` wrapper affect multiple layouts. |
| Child CSS | The child's `functions.php` loads its `style.css` after the parent styles. Edit that CSS directly. Parent SCSS partials are compiled through the parent entry point. |
| Child JavaScript | Add an enqueue to the child's `functions.php` on `wp_enqueue_scripts` at priority 120. Use a child-theme URL and depend on the `scripts` handle if it should follow `custom.js`. For a few instructions, use `wp_add_inline_script('scripts', …, 'after')` on the same hook. |

Compile `assets/css/main.scss` to `assets/css/main.css` after editing SCSS. The child theme's plain `style.css` loads directly. Verify desktop and mobile rendering and check the browser console after script changes.

## Workflow

GRIT gives agencies a shared foundation for custom WordPress sites. The agency defines the layouts and editing options. Editors manage content through ACF. Reuse existing theme and Bootstrap utilities first. Prepare queries and data in PHP, render markup in Twig, and define styles in SCSS.

The project controls its homepage through **Settings → Reading**. Transfer its ACF content and media separately, remapping attachment IDs as needed. Demo pages illustrate ACF setups. Register the `section` post type in the project, for example through ACF. The field-group import in `core/acf-fields.json` handles field definitions.

## Plugins and libraries

### WordPress plugins

TGMPA reads `core/plugins.php` to list plugins and display notices. Its automatic option can activate plugins after a TGMPA installation. Install licensed ACF PRO separately and use Composer for Timber and Twig.

| TGMPA declaration | Plugins |
| --- | --- |
| Required | ACF PRO, E-mail Log, Duplicate post, Contact Form 7, WP Maintenance Mode, Custom Post Type Permalinks, CopyPaste FlexContent Blocks for ACF, Post Meta Inspector, Complianz GDPR. |
| Recommended or optional | Responsive Lightbox Lite, Redirection, SG Speed Optimizer, SG Security Optimizer, Akismet, Jetpack, Sucuri Security, Yoast SEO. |

Check installed and active plugins on each site. ACF PRO supplies fields, CF7 supplies its forms, and Gallery lightboxes depend on the lightbox plugin's configuration.

### Frontend libraries

| Default with no saved settings | Libraries |
| --- | --- |
| Always loaded | WordPress jQuery, Bootstrap 4.6.2 with bundled Popper, Font Awesome, Animate.css with ViewportChecker, Hover.css. |
| Enabled by default with a Customizer switch | Owl Carousel, Masonry, ImagesLoaded, List.js, Jarallax with Video and Element, NProgress. |
| Disabled by default with a Customizer switch | GSAP, Three.js, Lenis, Locomotive Scroll, Lightbox2, Fitty, Swiper, Magic Mouse, Cocoen. |

Saved options override defaults. Jarallax, Video, and Element share a switch. List.js supplies Collapse search and pagination. Masonry arranges items of different heights. Owl powers carousels. Three.js, Swiper, and Cocoen require project-specific markup and initialization.

Shared scripts use WordPress jQuery. The grid, utilities, accordion, and tabs use Bootstrap 4 with its bundled Popper. Removing either dependency requires adapting the relevant markup, styles, and behavior. The Customizer has switches for optional libraries. Check the component's fallback after turning a library off.

### From setting to initialization

| Step | Files |
| --- | --- |
| Setting | `core/customizer.php` defines the control and initial value. `core/config.php` reads `grit_setting_*` into `$GLOBALS['assets_options']`. Keep defaults aligned. |
| Loading | `core/scripts.php` enqueues CSS and JS with WordPress handles and dependencies. `grit_scripts()` loads libraries at priority 100. `grit_scripts_custom()` loads `custom.js` at 110. |
| Initialization | `assets/js/custom.js` finds the markup and checks library availability before starting a component. Twig supplies markup and SCSS supplies presentation. |

For Owl, `grit_setting_owl_carousel` defaults to `true`. `GRIT_SETTING_OWL_CAROUSEL` enables the `owl_carousel` handle, added to the `custom.js` dependencies in block 27 when available. Block **03 | Owl carousels** checks `typeof $.fn.owlCarousel` and defines selectors and options. Change visible item counts through the documented classes.

`scripts.php` loads the structural and presentation assets directly. The `GRIT_SETTING_BOOTSTRAP`, `GRIT_SETTING_FA`, `GRIT_SETTING_ANIMATE`, and `GRIT_SETTING_HOVER` entries in `config.php` do not control those enqueues.

List.js is registered in block 27 and initialized in block 09 of `custom.js`. GSAP and Lenis use block 12. Maps uses the Customizer key, data from `core/extras.php`, `section_maps.twig`, and `assets/js/maps.js`.

### Adding or removing a library

1. Add a Customizer control and config entry if the site needs a switch. Enqueue assets in `scripts.php` and initialize the component in `custom.js`. Declare the actual dependencies and check that the library is available before initialization.
2. To disable an optional library on an existing site, use its Customizer switch. The saved setting takes precedence over a changed code default.
3. To remove it from the starter, find its option, `GRIT_SETTING_*` key, enqueue handle, JavaScript calls, markup, and styles. Review shared assets and licenses before removing files.

Use `GRIT_SETTING_CSS` and `GRIT_SETTING_JS` for additional asset URLs. Use explicit enqueues in `scripts.php` when scripts require dependency ordering. Check the Network panel for duplicate loads, the console for errors, and desktop and mobile behavior with the option enabled and disabled.

## Common fields and columns

Use the **Sections** Flexible Content field where ACF location rules make it available. Each layout has a **Guida** tab with class and library notes. Field descriptions give shorter instructions. The tab is informational.

| Field | Purpose |
| --- | --- |
| Class | Structural, presentation, and behavior classes on the section. |
| Inner Class | Columns and modifiers on an individual chapter, card, or group. |
| Contained | Constrains the inner width. Turn it off for an extended layout. |
| Pre Content | Places the section before WordPress content when enabled and after it otherwise. |
| Background Color / Text Color | Wrapper colors. Check button contrast separately. |
| Align | Text alignment. Use column alignment classes for vertical positioning. |
| Link 1 / Link 2 and colors | Optional links rendered by the shared button component. |

Section Text renders Title as h2 and Subtitle as h3. To add an introductory h1 in formatted content, leave the chapter title empty and use a single h1 for the page. Keep headings hierarchical and provide descriptive alt text for informative images.

### Layout and behavior classes

Choose the layout, then the columns and appearance. Enter tokens without a leading dot. Empty fields use the defaults.

| Purpose | Example | Field |
| --- | --- | --- |
| Columns | `col-12 col-md-6` | Inner Class on a chapter or card. One column on mobile and two from 768 px. |
| Spacing | `py-5` / `mb-4` | Class for the section or Inner Class for an item. |
| Layout mode | `section_carousel_text` / `section_masonry` | Section Text Class. |
| Carousel options | `carousel-items-1 carousel-items-md-2` | Class on a section with a carousel already enabled. |
| Image effect | `parallax` / `parallax-gsap` | Static Section Text chapter Inner Class. Requires Jarallax or GSAP respectively. |
| Project style | `servizi-card` | Class on the intended element with its rule in project or child CSS. |

Use each layout's own activation class and enable its library in the Customizer.

| Section Text layout | Class | Inner Class | Additional library |
| --- | --- | --- | --- |
| Two columns from tablet | `py-5` | `col-12 col-md-6` | None |
| Two-column Masonry from tablet | `section_masonry py-5` | `col-12 col-md-6` | Masonry |
| Carousel with one item on mobile and two from tablet | `section_carousel_text carousel-items-1 carousel-items-md-2` | Leave column widths empty | Owl Carousel |

### Shared columns

`col-12 col-md-6 col-lg-4` gives one, two, and three columns at the base, md, and lg widths. Spacing utilities include `mb-4`, `p-4`, `py-5`, and `pt-md-7`.

| Chapters or cards | Automatic columns |
| --- | --- |
| 1 | `col-12`. Center alignment uses `col-12 col-md-10 col-xl-8`. |
| 2 | `col-12 col-md-6` |
| 3 | `col-12 col-sm-6 col-md-4` |
| 4 or more | `col-12 col-sm-6 col-md-3` |

Explicit `col` or `col-*` tokens replace automatic widths. Owl removes column tokens and keeps other modifiers. Set visible counts through `carousel-items-*`.

Breakpoints are base 0, sm 576, md 768, lg 992, xl 1200, and xxl 1400 px. Use xxl where the theme implements it, such as Owl and Gallery settings. Standard Bootstrap 4 utilities have their own breakpoint coverage.

## Section Page and reusable content

Create a source page with sections for shared calls to action, contact details, or other content. Add Section Page to each destination and select the source. Editing the source updates its references.

A draft source can supply content to a public destination. Treat draft sources as reusable content and keep private information elsewhere. Password-protected source pages retain their protection.

References expand one level. Nested Section Page rows are skipped. Each source section keeps its own Pre Content placement.

IDs derive from the destination row and source item. `section_id_2-1` identifies the first section referenced by row two. Repeated references get distinct IDs. Reordering rows changes these anchors.

The renderer is `templates/partials/sections.twig`. The main templates call it before and after content. Available sections depend on the ACF object loaded by the controller.

## Section Text

The ACF Chapters repeater includes an image, title, subtitle, WYSIWYG content, two links, and Inner Class.

| Class | Mode |
| --- | --- |
| Empty | Bootstrap grid |
| `section_masonry` | Masonry, with a Bootstrap grid fallback |
| `section_carousel_text` | Owl carousel. Takes priority over Masonry if both classes are present. |

Text carousel counts default to 1 / 2 / 3 / 3 / 4 / 4 from base through xxl. Static layouts use the [shared column rules](#shared-columns). For carousel settings see [Shared Owl carousels](#shared-owl-carousels).

### Image aspect ratios

Apply these classes to the section's Class field.

| Class | Effect |
| --- | --- |
| `text-image-ratio-square` | 1:1 frame |
| `text-image-ratio-landscape` | 4:3 frame |
| `text-image-ratio-portrait` | 3:4 frame |
| `text-image-ratio-auto` | Original proportions |
| `text-image-fit-cover` | Fill and crop as needed. Default for fixed ratios. |
| `text-image-fit-contain` | Show the whole image with space where needed. |

Choose one ratio and one fit. Ratios apply across breakpoints and align image frames. Card height still depends on content. Use fit classes for standard images. Parallax containers handle their own sizing.

```text
section_carousel_text carousel-items-1 carousel-items-md-2 carousel-items-xl-3 text-image-ratio-landscape text-image-fit-cover
```

Images use `wp_get_attachment_image`, the `large` size, and available `srcset`. Carousel `sizes` estimates the width from visible counts and the viewport. Static and autoWidth layouts use `100vw` as the estimate. The browser chooses from existing image variants.

### Parallax and content

For static chapters, set `parallax` or `parallax-gsap` in `inner_class` and enable the respective library. GSAP takes priority. Carousels skip chapter parallax to avoid conflicts with Owl transforms and clones.

Title renders as h2 and subtitle as h3. The WYSIWYG keeps its HTML. The shared partial `templates/partials/text-chapter.twig` escapes titles and attributes, filters links through `esc_url`, and renders buttons with URLs. Links targeting `_blank` use `rel="noopener noreferrer"`.

Masonry initializes once per `.js-grit-masonry` grid and updates after images and fonts load. This selector avoids Masonry's HTML auto-initialization. Jarallax initializes independently of Owl when available. Styles live in `assets/css/_sections.scss` and Owl controls in `assets/css/_plugins.scss`.

### Section background image

**Background Image** under Style sets a decorative image for the section, independently of chapter images. Add `parallax` to the section for Jarallax. A static image remains available with reduced motion or when the library is unavailable.

Use `text-background-overlay` for a 40% black overlay or `text-background-overlay-light` for 40% white. Choose a readable text color. Content and spacing such as `py-7` determine the height. Background Half applies to color. Background images work with the grid, Masonry, and carousel.

### Overlapping header panel

Use `text-header-overlap` with Background Image and one static chapter. The text panel overlaps the bottom of the image and grows with the content. Try `col-12 col-md-10 col-lg-8` in Inner Class. Override the white and dark defaults with `--header-panel-background` and `--header-panel-color`. Use this composition in a static grid. For breadcrumbs, put `[wpseo_breadcrumb]` in the text field.

### Hero and CTA alignment

- `text-columns-top`, `text-columns-center`, `text-columns-bottom`, and `text-columns-stretch` align static columns. Set one in Class.
- `text-content-top`, `text-content-center`, `text-content-bottom`, and `text-content-between` distribute chapter groups. Set one in Class or Inner Class. Between needs free space and treats the Text field as a group.
- `text-image-after` places the photo after text and buttons.
- `text-height-medium` gives chapters a minimum height of `70svh` and allows taller content.

These modifiers apply to static grids. For uneven chapters use `section_masonry`, the shared Text and Archive controller, and `$masonry-item-gap` for vertical spacing. Try one, two, and three columns with varying content lengths.

## Section Gallery

| Images | Class | Result |
| --- | --- | --- |
| None | Any | Empty |
| One | No parallax class | Responsive single image |
| One | `parallax` | Jarallax if enabled |
| One | `parallax-gsap` | GSAP parallax. Takes priority if both effects are specified. |
| Multiple | `gallery_carousel` | Shared Owl carousel |
| Multiple | No carousel class | WordPress `[gallery]` grid |

Put single-image parallax classes in the section's Class field. For the grid, `[gallery]` links to image files through `link="file"`. Configure Responsive Lightbox Lite and the project's Nivo library to handle those links. Verify single images and Owl clones against the plugin settings and markup.

### ACF fields and grid settings

**Gallery** sets image selection and order. **Columns** sets 1–4 columns from 576 px by default. Below 576 px the grid uses one column. The default gap is 8 px. **Size** chooses the static grid image variant (thumbnail, medium, large, full).

- `gallery-cols-N` sets 1–12 columns. `gallery-cols-sm-N`, `gallery-cols-md-N`, `gallery-cols-lg-N`, `gallery-cols-xl-N`, and `gallery-cols-xxl-N` apply from 576, 768, 992, 1200, and 1400 px.
- `gallery-gap-N` sets a gap of 0–500 px. Use `gallery-gap-sm-N`, `gallery-gap-md-N`, `gallery-gap-lg-N`, `gallery-gap-xl-N`, or `gallery-gap-xxl-N` for a breakpoint override.

Add space-separated tokens in Class. Each explicit value persists until the next override for that option. JavaScript applies the modifiers and the grid falls back to ACF defaults without it.

### Aspect ratios and thumbnails

| Class | Effect |
| --- | --- |
| `gallery-ratio-square` | 1:1 |
| `gallery-ratio-landscape` | 4:3 |
| `gallery-ratio-portrait` | 3:4 |
| `gallery-ratio-auto` | Original proportions |
| `gallery-fit-cover` | Fill the frame, cropping when needed. Default for fixed ratios. |
| `gallery-fit-contain` | Keep the whole image inside the frame. |

Choose one ratio and fit. Both work across all breakpoints in the grid and carousel. The single-image parallax branch has its own layout. Ratios affect the frame and leave the linked original intact.

```text
gallery-cols-1 gallery-cols-md-2 gallery-cols-xl-4 gallery-gap-20
```

```text
gallery-cols-1 gallery-cols-sm-2 gallery-cols-lg-3 gallery-ratio-square gallery-fit-contain gallery-gap-10 gallery-gap-lg-30
```

For a carousel use `gallery_carousel` and `carousel-*`. The `gallery-cols-*` and `gallery-gap-*` classes control the grid. Carousel images use `wp_get_attachment_image` with `large`, width and height, and available `srcset`. Their `sizes` estimates width from `carousel-items-*` or uses `100vw` for base autoWidth. The browser chooses from existing variants. Container width, gaps, and stage padding can reduce the actual width.

```text
gallery_carousel carousel-items-1 carousel-items-md-2 carousel-items-xl-3 gallery-ratio-landscape gallery-fit-cover
```

Uniform frames grow with card width. Disable autoWidth for predictable visible counts. Grid styles live in `assets/css/_sections.scss` and Owl controls in `assets/css/_plugins.scss`. Recompile `main.scss` after SCSS changes. [Shared Owl carousels](#shared-owl-carousels)

## Section Collapse

| Class | Mode |
| --- | --- |
| Empty | Grouped accordion with the first item open in each group |
| `section_collapse_search` | Flat searchable list with independent pagination and seven results per page |
| `section_collapse_dynamic` | Tabs containing text, a grid, or a carousel per group |

Search takes priority over dynamic tabs. The ACF Lists repeater contains `args` (group name), `args_color`, `inner_class`, and `item` (title, WYSIWYG, two links). Buttons can render with empty text, including in dynamic grids.

### Tab group Inner Class

- Empty renders sequential text.
- `grid` gives one column on mobile and three from md.
- `grid col-12 col-md-6` gives two columns from md.
- `carousel` activates Owl.
- `carousel carousel-items-1 carousel-items-md-2 carousel-no-loop` configures one group.
- Other values apply their classes to the text layout.

Section options apply to all carousels. Group options take priority for the same setting and breakpoint. Put positioning classes for controls on the section wrapper. Collapse uses standard counts of 1 / 2 / 3 / 4 / 5 / 5. [Shared Owl carousels](#shared-owl-carousels)

### Search and interaction

List.js 2.3.1 ships in `assets/list-js` with its license. When enabled, WordPress loads it once as a `custom.js` dependency. Each section has its own seven-result pagination. Search matches title, content, and group case-insensitively. Accent handling follows List.js. Searches and resets return to page one. Each section handles its own empty states. The complete list remains available without JavaScript. Set the page size in the search controller.

Bootstrap 4 drives accordions and tabs. Opening a tab refreshes its hidden Owl carousel. IDs derive from section, group, and item positions, so duplicate group names work. Headings use buttons with ARIA attributes. Bootstrap events update decorative icons. Titles are escaped, WYSIWYG HTML is retained, and URLs pass through `esc_url`. Links targeting `_blank` use `rel="noopener noreferrer"`. Standard groups can each keep an item open. Search uses one accordion per section.

Edit modes and IDs in `templates/sections/section_collapse.twig`, accordion markup in `templates/partials/collapse-item.twig`, and buttons in `templates/partials/buttons.twig`. Search, pagination, icons, and tab updates live in `assets/js/custom.js`. Use `assets/css/_sections.scss` for Collapse and `assets/css/_plugins.scss` for shared controls.

## Section Archive

Show an independent selection of published posts or terms. Section Archive has its own query and no numbered pagination. WordPress's main query and the `archive_posts` and `archive_section` lists used elsewhere remain separate.

### Posts mode

| Field | Behavior |
| --- | --- |
| Post Type | Registered public types excluding attachments. An empty value defaults to `post`. |
| Tease | Card template name without `tease-` or `.twig`. Empty selects the post-type template if available or a standard card. WooCommerce cards require their integration. |
| Inner Class | Card columns and modifiers such as `col-12 col-md-6 mb-4`. |
| Number of posts | 1–100. Empty uses **Settings → Reading**. |
| Order by | Date, title, or `menu_order`. ID breaks ties. |
| Direction | `DESC` or `ASC`. Default is newest first by date. |
| Exclude current content | Off by default. On single posts and pages, excludes the current object even when rendering a Section Page reference. |
| Taxonomy | Optional. Select a taxonomy associated with the post type. |
| Term slugs | Comma-separated slugs. Matches at least one (OR/IN). Empty skips filtering. Invalid filters or zero results hide the section. |
| Contained, Pre Content, colors, Align, Class | Use the shared section rules. |

The query includes published posts and excludes password-protected posts. Use Date and `ASC` for oldest first. Term slugs are the machine names. With `category` and `notizie,eventi`, the section matches posts in Notizie or Eventi. Hierarchical taxonomy filters normally include descendants. Admin filters identify fields by name and check the `section_archive` layout.

### Terms mode

Set `archive_mode` to `terms` instead of the default `posts`. This uses `get_terms()` on a public taxonomy. A term card contains a name, archive link, optional 35-word description, and optional WordPress count. Post type, Tease, term-slug filtering, post ordering, and current-post exclusion apply to Posts mode.

| Field | Behavior |
| --- | --- |
| `taxonomy` | Required public taxonomy. |
| `posts_per_page` | Shared limit, up to 100. |
| `terms_orderby` | `name`, `count`, or `term_id`. |
| `order` | `ASC` or `DESC`. |
| `terms_hide_empty` | Hides empty terms according to WordPress. |
| `terms_parent` | Parent slug. Returns direct children in the same hierarchical taxonomy. |
| `terms_top_level` | Root terms with parent zero. Applies to hierarchical taxonomies when no parent is set. |
| `terms_show_description` | Shows a shortened plain-text description. |
| `terms_show_count` | Shows WordPress's count without recalculating it by post type. |

An invalid or non-public taxonomy, a missing parent, or a parent filter on a flat taxonomy yields no section. Terms use `templates/partials/tease-term.twig` and have no term-image field.

### Grid, carousel, and Masonry

Use an empty Class for a grid. The exact token `section_archive_carousel` enables Owl when there are at least two results. One result stays static. It takes precedence over `section_masonry`, even when both are present. Both modes support Posts and Terms. Owl falls back to a readable sequence when unavailable.

Inner Class controls the cards, using [shared columns](#shared-columns) when no widths are given. In Owl, column tokens are removed and other modifiers remain. Column tokens in the section's Class field size the outer list container. Owl defaults to 1 / 2 / 3 / 3 / 3 / 3 items with loop disabled. ### Associating a page with a post type

The controller matches the page path against the registered type name, a string `has_archive`, or its `rewrite` slug. A `progetto` type with rewrite slug `progetti` can use the page `progetti`. A page named `blog` can represent standard posts. Use an unambiguous match. A Template Archive page without a valid match has no results.

`has_archive` enables or names the archive. `rewrite` controls URL rewriting. Check both when registering the post type and resolving slug conflicts. A native archive can use its own data when there is no associated page ID for ACF sections. Protected pages retain their password restrictions.

### Post types in term archives

Edit `$archive_post_types` inside `grit_taxonomy_archive_post_types()` in `core/extras.php`.

```php
$archive_post_types = [
    'category' => ['post'],
    'post_tag' => ['post', 'section'],
    // 'settore' => ['progetto'],
];
```

- `[]` uses public types assigned to the taxonomy and preserves explicit query filters.
- `['post']` limits results to blog posts.
- `['section']` limits results to Sections if registered for that taxonomy.
- An explicit list takes priority over the URL's `post_type` filter and is intersected with the taxonomy's assigned types. Invalid or unrelated types yield no results.

The filter runs before pagination and preserves term assignments.

### Twig archive priority

| Archive | Most specific to generic |
| --- | --- |
| Post type | `archive-{post_type}.twig` → `archive.twig` → `index.twig` |
| Category | `category-{slug}.twig` → `category-{ID}.twig` → `category.twig` → `archive.twig` → `index.twig` |
| Tag | `tag-{slug}.twig` → `tag-{ID}.twig` → `tag.twig` → `archive.twig` → `index.twig` |
| Custom taxonomy | `taxonomy-{taxonomy}-{term-slug}.twig` → `taxonomy-{taxonomy}.twig` → `taxonomy.twig` → `archive.twig` → `index.twig` |

Place variants in `templates/`. Use registered names for `post_type` and `taxonomy`. The file `archive-progetto.twig` uses the post type name even when its rewrite slug is `progetti`. The controller defines the lookup order.

### Search sections

`search.php` looks for the current page using Template Search, then a published `search` or `cerca` page, then a single published page assigned to Template Search. An associated page supplies content and ACF layouts before and after results.

Native search keeps WordPress's query. The Search page queries the submitted term and shows an empty state for an empty query. `grit_template_fields()`, `grit_template_content()`, and `grit_template_query()` in `core/extras.php` prepare fields, formatted content, counts, and ranges. Use real page IDs only for views with an associated page.

### Color values and transparency

```scss
$black-50: #808080;             // Opaque grey.
$black-50-rgb: $black-50;       // A Sass color alias.
$black-50-rgba: rgba($black, .5); // Black at 50% opacity.
```

Sass color functions accept hexadecimal colors. The `-rgb` name is an alias. Sass chooses the emitted CSS format based on context. A channel list such as `128, 128, 128` is a different value. Opaque grey and translucent black behave differently over other colors.

## Agency branding

Set `GRIT_AGENCY` near the top of `functions.php`, before core modules load.

```php
if (!defined('GRIT_AGENCY')) {

}
```

The value matches `agency_folder` in `assets/credits/credits.json`. The included records are `gritlab`, `astratto`, and `poliedro`. Missing or invalid choices fall back to GRIT. A child theme can define the constant before the parent loads.

Missing assets fall back individually to `gritlab`. Folder names allow lowercase letters, digits, hyphens, and underscores.

## Updates and troubleshooting

### Updating a project

Setup skips ACF groups with keys already present. Use ACF's import tools and check the resulting definitions when updating an existing site.

1. Back up files, the database, Customizer options, and ACF data.
2. Review local modifications before replacing the theme or importing JSON.
3. Install dependencies from the intended manifest and lock file.
4. Preserve used ACF keys and layouts or migrate saved data explicitly.
5. Recompile Sass if sources changed.
6. Clear relevant caches and check the frontend and admin.

### Checks after changes

- Validate changed PHP and JavaScript and compile SCSS.
- Render Twig with zero, one, and multiple items and with long text.
- Check homepage, inner page, single post, category, tag, custom taxonomy, post type archive, and search, including empty results.
- Check mobile and overlay menus, keyboard navigation, focus, buttons, and responsive layouts.
- Check multiple Owl, Maps, and GSAP instances, resizing, optional libraries disabled, and reduced motion.
- Check links, images, form delivery, consent, and external services on the target domain.

| Symptom | Check |
| --- | --- |
| Timber is missing | Composer, `vendor/autoload.php`, and compatible Timber 1.x |
| Fields are missing | ACF PRO, imported JSON, and location rules |
| Only the homepage works | DNS, virtual host, permalinks, and server rewrites |
| Empty category | Term assignments, post-type taxonomy association, `$archive_post_types`, and main query |
| Hidden Section Archive | Valid filters, published content, taxonomy associations, or available terms |
| Missing Owl arrows | Library, overflow, arrow settings, breakpoint, and room for controls |
| Blurry Gallery images | ACF Size, source images, and available thumbnails and `srcset` |
| Static GSAP | Switch, viewport, motion preference, class, overflow, and panel height |
| Invisible bars | GSAP, viewport, contrast, and section height |
| Missing map | Key, domain restrictions, service, consent, coordinates, and console |
| Shortcode shows literally | A rendering path that runs `do_shortcode`, a valid name, and correct IDs |
| Documentation example executes | Double square brackets around the shortcode in WordPress |
| SCSS change is missing | Compilation of `main.scss`, loaded asset, and cache |

Check relevant logs and redact private data and credentials when sharing them. Diagnose failures in the affected component.
